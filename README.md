I work at the intersection of **offensive security**, **blue team operations**, and **cloud infrastructure**. This profile is a collection of hands-on labs, tools, and projects I've built to sharpen those skills — focused on Active Directory, threat detection, adversary simulation, and cloud security.

---

## Focus Areas

- 🔴 **Red Team** — AD exploitation, privilege escalation, lateral movement, C2 frameworks
- 🔵 **Blue Team / SOC** — SIEM engineering, detection rules, alert triage, threat hunting
- ☁️ **Cloud Security** — Azure attack surface, misconfiguration detection, cloud-native monitoring
- 🏗️ **Infrastructure Security** — Active Directory hardening, network segmentation, endpoint visibility

## Projects

### 🔵 [Azure Security Lab](https://github.com/austinerenson/azure-security-lab) *(Active)*
Multi-phase home lab on Azure — covers threat detection with Microsoft Sentinel, Defender for Cloud, AD security, offensive simulation, and DevSecOps pipelines. Built to mirror realistic enterprise environments.

`Azure` `Microsoft Sentinel` `Defender for Cloud` `Active Directory` `KQL`

---

### 🟣 [Active Directory Attack & Defense Lab](https://github.com/austinerenson/ad-lab-home)) *(Active)*
On-prem AD environment for simulating common attack paths (Kerberoasting, Pass-the-Hash, DCSync) and building detections against them. Domain Controller + workstation setup with logging pipelines.

`Windows Server` `Active Directory` `Kerberos` `PowerShell` `Splunk / Sentinel`

---

### 🔴 [Red Team Playbooks](https://github.com/austinerenson/redteam-playbooks) *(In Progress)*
Documented attack chains and TTPs mapped to MITRE ATT&CK. Built for lab use — covers initial access, persistence, lateral movement, and exfiltration scenarios.

`MITRE ATT&CK` `Cobalt Strike` `Metasploit` `PowerShell` `C2`

---

### ⚙️ [DevSecOps / CI-CD Security](https://github.com/austinerenson/devops-projects) *(In Progress)*
Pipeline security experiments — secrets scanning, container hardening, IaC misconfiguration detection, and integrating security gates into Azure DevOps pipelines.

`Azure DevOps` `Docker` `Kubernetes` `Trivy` `Checkov`
